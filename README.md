# Financial Behavior and Customer Spending Analysis

## Project Overview
This project analyzes customer financial behavior and spending patterns using banking and transaction datasets. The main purpose of this project is to understand customer transaction activities, account behavior, investment patterns, and overall financial characteristics through data analysis and visualization techniques.

The project also focuses on identifying different customer groups based on financial behavior using customer segmentation techniques. The analysis was performed using Python, Pandas, Matplotlib, Seaborn, and machine learning techniques.

## Project Objectives

The main objectives of this project are:

- To analyze customer financial behavior and transaction activities
- To understand customer spending and investment patterns
- To identify relationships between important financial variables
- To visualize customer financial activities using charts and graphs
- To group customers into different financial behavior segments
- To gain practical experience in financial data analysis and customer analytics

  ## Dataset Information

This project uses banking and transaction datasets containing customer information, transaction details, account information, and investment-related variables.

The datasets include:
- Customer dataset
- Transaction dataset
- Bank dataset

Important variables used in this project include:
- Customer age
- Customer type
- Account type
- Transaction amount
- Total balance
- Investment amount
- Investment type
- Region and city information


## Tools and Technologies Used

The following tools and libraries were used in this project:

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


## Data Preprocessing

Several preprocessing steps were performed before the analysis:

- Loaded and explored the datasets
- Checked dataset structure and variables
- Identified missing values
- Handled missing values using median and mode methods
- Checked duplicate records
- Performed descriptive statistical analysis

These preprocessing steps helped improve the quality and consistency of the dataset before visualization and segmentation analysis.

## Exploratory Data Analysis

Different visualizations and analyses were performed to better understand customer financial behavior.

The analysis included:
- Distribution of transaction amounts
- Distribution of customer types
- Relationship between customer age and total balance
- Investment type analysis
- Correlation analysis of financial variables

These visualizations helped identify financial behavior patterns and relationships between important variables.


## Customer Segmentation Analysis

Customer segmentation was performed using the K-Means clustering algorithm. Customers were grouped into different segments based on:
- Age
- Total balance
- Transaction amount
- Investment amount

The segmentation analysis helped identify different financial behavior groups within the dataset. Some customer groups showed higher transaction and investment activity, while other groups demonstrated lower financial activity and balance patterns.


## Key Findings

Some important findings from this project include:

- Customers demonstrate different spending and financial behavior patterns
- Transaction activity varies across customer groups
- Investment behavior differs between customer segments
- Some financial variables show moderate relationships with each other
- Customer segmentation helps provide a clearer understanding of financial behavior patterns


## Banking and Analytical Perspective

From a banking perspective, customer financial behavior analysis is important for understanding customer activities, transaction habits, and financial preferences. In banking operations, transaction behavior and financial patterns often help institutions understand customer needs and support better financial decision-making.

This project also provided practical experience in customer analytics, financial data analysis, visualization, and segmentation techniques commonly used in data analytics and banking environments.

This project provided a practical understanding of customer financial behavior analysis using real-world style banking and transaction datasets. Different data analysis, visualization, and customer segmentation techniques were applied to explore customer financial activities and spending behavior.
